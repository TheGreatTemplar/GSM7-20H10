# GSM7-20H10 · Semiconductor Testbench

**Версия 0.2.0 · 15.11.2026.** Автономные серии LIST, токи диодов до 100 мА, 2/4 провода и FRONT/REAR, сохранение последних настроек, смена осей, встроенная справка и иконка. Версия и дата отображаются в «Справка → О программе»; номер версии также указан в заголовке окна.

Настольная программа на Python / Qt для отбора диодов и J310. Компоновка и палитра ориентированы на [ADC-DAC-testbench](https://github.com/TheGreatTemplar/ADC-DAC-testbench): настройки слева, график сверху, измерения, подбор и журнал снизу.

## Запуск на Windows

Нужен Python 3.12 или новее. В PowerShell из папки проекта:

```powershell
.\setup.ps1
.\start.cmd
```

При нестандартном пути: ` .\setup.ps1 -Python 'C:\path\python.exe' `.
В уже подготовленном окружении: `.venv\Scripts\python.exe app.py`.
При первом запуске выбран **демо-режим**. В дальнейшем восстанавливаются последние настройки: режим связи, адреса, БД, методика, образец, маркировка, партия, точки, генератор ряда, предел, задержка, температура, схема подключения, выбранные вкладки, оси и параметры подбора. Настройки автоматически записываются в `settings.local.json` после изменения, перед запуском операции и при закрытии. Укажите маркировку, номер и партию, нажмите «Измерить образец». Меняйте номер при установке следующего компонента.

Меню **«Справка → Помощь по программе»** (F1) открывает встроенное руководство без интернета: подключение, измерения, подбор, БД и ошибки. **«Справка → О программе»** показывает версию и ссылку на проект. Иконка окна и панели задач — диод и кривая ВАХ. Исходник находится в `assets/gsmbench.svg`, Windows-иконка с размерами 16–256 — в `assets/gsmbench.ico`, PNG для просмотра — в `assets/gsmbench.png`. Пересобрать их можно командой `.venv\Scripts\python.exe tools/build_icon.py`. Для ярлыка Windows укажите `assets/gsmbench.ico` через свойства ярлыка; файл `start.cmd` использует стандартную иконку командных файлов.

Установка также создаёт в папке проекта ярлык **GSM7-20H10.lnk** с новой иконкой. Его можно скопировать на рабочий стол. На каждом ПК ярлык создаётся заново с локальными путями; для пересоздания выполните `.\create-shortcut.ps1`.

## Методики первой версии

Начальная маркировка диода — **КД419**, стартовый ряд — **20 логарифмических точек от 1 мкА до 11 мА**, ограничение напряжения **1 В**. Это план сравнения ВАХ, а не паспортные пределы семейства. В поле маркировки указывайте полное обозначение с буквой: разные исполнения должны подбираться отдельно. Для окончательного профиля нужны буквенное исполнение и паспорт конкретных диодов.

Генератор точек: выберите «Логарифмический» или «Линейный», задайте «От / до» и «Число точек», нажмите **«Задать точки»**. Для диодов единицы диапазона — **мА**: `0.001` соответствует **1 мкА**, `11` — **11 мА**. Оба конца включены в число точек. В линейном ряду одинаковый шаг, в логарифмическом — одинаковое отношение соседних токов. Измерение использует сформированный список «Токи, мА», который можно редактировать вручную. Для J310 генератор задаёт напряжения в вольтах.

- **Диод**: источник тока, измерение Vf на нескольких точках. Токи вводятся в мА через `;`, например `0.1; 0.3; 1; 3; 10`. Ограничение напряжения настраивается. HI → анод, LO → катод на выбранной панели. Максимум программы: 100 мА и 2 В. Это пределы программы, допустимость для конкретной марки нужно проверить по её документации.
- **J310**: источник Vds, измерение Id при G–S, соединённых вместе. HI → D, LO → S на выбранной панели. Начальный диапазон 0,5–5 В, 20 точек, ограничение 50 мА. Таблица показывает ток в последней точке; сравнивать Idss следует при одинаковых условиях и в области насыщения. Пределы программы: 10 В, 100 мА, произведение Vds × Iлим ≤ 0,3 Вт. Цоколёвка зависит от производителя и корпуса.
- Подбор пар или четвёрок: выделите строки Ctrl/Shift и откройте «Подбор». Критерий — максимальный разброс Vf (мВ) или Id (мА) **по всем точкам**. Условия, температура, марка, партия и режим должны совпадать. Один номер образца не может войти в группу дважды. Результаты — кандидаты, группы могут пересекаться. Ограничение поиска: 60 выбранных измерений, 100 лучших групп.
- Незавершённые и ошибочные измерения сохраняются, но не участвуют в подборе. Ограничение источника и переполнение считаются ошибкой измерения.

Подбор по прямой ВАХ не измеряет ёмкость перехода и ВЧ-параметры диода. Для J310 пока нет Vgs(off), gm и шумовых измерений; для независимого изменения Vgs нужен дополнительный источник/оснастка. Обратные токи диодов в эту версию не входят.

Во вкладке **«Связь / БД»** доступны **«Схема»** (2 провода / 4 провода Kelvin) и **«Клеммы»** (FRONT / REAR). При 4 проводах отдельно подведите SENSE HI/LO к тем же выводам компонента, что и токовые HI/LO. Настройки применяются только перед серией при выключенном выходе; программа проверяет подтверждение выбранных клемм и remote sense. Схема и панель сохраняются в рецепте и учитываются при подборе. Старые измерения без этих полей трактуются как FRONT, 2 провода. Подсказка поля токов показывает вертикальный нумерованный список; длинные списки разбиваются на колонки с ограничением первых 75 точек.

Кнопка **«Поменять оси»** над графиком переключает X = U, Y = I ↔ X = I, Y = U. Меняются все отображаемые кривые, подписи и единицы. Новые данные используют выбранное направление осей; исходные измерения в БД сохраняются в прежних единицах СИ.

Серия выполняется самим прибором в режиме **LIST**: программа загружает точки, задаёт буфер и число измерений, затем отправляет `:INIT`. Автоотключение работает в режиме **TCOUNT**, то есть в конце всей серии, без выключения между точками. Для источника задано `:SOUR:SWE:RANG AUTO`, чтобы диапазон переключался для каждой точки, включая малые токи. Во время расчётного времени серии программа оставляет канал команд свободным: на V1.24 запрос числа точек во время выполнения блокирует обработку ABOR. Готовность проверяется после ожидания с запасом (N × (задержка + 0,25 с) + 0,5 с); результат может появиться немного позже фактического окончания измерения. После подтверждения числа точек программа отключает выход и считывает все результаты одной командой `:FETC?`. По кнопке СТОП ожидание немедленно прерывается, отправляются `:ABOR` и OUTPUT OFF, затем проверяется отключение. При ошибке или незавершённой серии данные не участвуют в подборе. Поддерживаются до 200 точек, список передаётся блоками до 100 точек.

## Ethernet

Начальный IP: **172.16.236.32**, TCP-порт **5025** (сообщены владельцем прибора). Оба значения редактируются во вкладке подключения. Доступны TCP socket и VISA LAN с полным ресурсом `TCPIP…`. Для VISA используется PyVISA-py. Совместимость VISA-транспорта необходимо проверить на конкретной прошивке. Для VISA используется адрес внутри ресурса; отдельное поле IP относится к TCP socket.

Кнопка «Проверить связь» выполняет только `*IDN?`, не включает выход. Измерение разрешено только для идентификатора GSM7-20H10/GSM-20H10. При измерении устанавливаются выбранные клеммы и схема 2/4 провода, источник LIST, ограничения и отключение в конце серии. Программа сбрасывает настройки прибора перед серией. После остановки/ошибки отправляет OUTPUT OFF и проверяет подтверждение. При обрыве сети подтверждение отключения невозможно — проверьте OUTPUT на передней панели. Программный СТОП не является аппаратной аварийной кнопкой. Если фактическая серия длится дольше расчётного запаса и запрос готовности уже отправлен, прошивка может задержать обработку ABOR до конца серии; длинное ожидание ответа больше не обрывается через обычные 3 секунды. При прерывании ожидающего запроса поток ответов синхронизируется по IDN, чтобы запоздавшее число точек не принять за состояние выхода.

Проверка СТОП 15.11.2026 на V1.24 через VISA SOCKET: серия 20 точек 1–4 мкА, ограничение 1 В, задержка 1 с; СТОП на 10-й секунде. В буфере осталось 9 точек, OUTPUT OFF подтверждён примерно через 15 мс после отправки остановки. Также проверена обычная серия из четырёх точек с задержкой 1 с: четыре результата получены, очередь ошибок пуста, выход выключен. Для повторения этой аппаратной диагностики есть `tools/check_list_stop.py` (`--visa`, `--long`, `--no-stop`); скрипт включает выход в указанных пределах и не пишет результаты в рабочую БД.

Команды сверены с [руководством производителя GSM-20H10](https://www.gwinstek.com/en-GB/products/downloadSeriesDownNew/21140/2192), разделы LAN и Command Details. На V1.24 проверена загрузка 20 токов от 1 мкА до 11 мА, число точек LIST, буфера, триггеров и режим TCOUNT. Пользователь выполнил автономную серию. Выявлено: `:TRAC:DATA?` возвращает U,I,R независимо от `FORM:ELEM`, а `:FETC?` корректно возвращает выбранные U,I,STAT; это проверено повторным чтением одной сохранённой серии без нового измерения. `9.91e37` в поле R — признак отсутствующего сопротивления, не слово состояния. Проверка статуса сохраняется, фиктивный нулевой статус не подставляется. Отрицательное Vf при положительном заданном токе отклоняется как недостоверная прямая ВАХ. AUTO для диапазонов серии принят прибором без ошибок; новый прогон с этим режимом ещё требуется. Для FEED прошивка принимает `SENS`, но отвергает документированный параметр `SENS1` с ошибкой -140.

15.11.2026 проверена связь через TCP socket `172.16.236.32:5025`: ответ на `*IDN?` — `PRIST,GSM7-20H10,012345678,V1.24`. При проверке выход не включался.

Особенности V1.24, обнаруженные при проверке сброса: `*OPC?` возвращает `0` даже в состоянии покоя; после `*WAI` LAN перестал отвечать. Поэтому драйвер не использует эти команды: после `*RST` выдерживает 1 с, проверяет очередь ошибок и подтверждает OUTPUT OFF. Исправленный вариант требует повторной аппаратной проверки после перезапуска прибора.

## Существующая БД и два компьютера

Найдена SQLite-база кварцев `D:\HAM\QuartzLab\Projects\database\QuartzLab.db`. Выберите её во вкладке подключения и сохраните настройки. При первом сохранении программа делает SQLite backup рядом с базой, затем добавляет только таблицы `gsm_schema` и `gsm_run`. Существующие таблицы кварцев и их версия схемы не изменяются. `gsm_run` содержит UUID и JSON с исходными точками, рецептом, прибором, ПК, временем UTC и статусом. SQLite JSON-функции позволяют анализировать поля SQL-запросами.

Демо всегда использует отдельную `data/demo.db`. Если запись результата в основную БД не удалась, резерв находится в `data/pending`; кнопка восстановления повторяет запись для выбранной БД. Ошибка записи отображается пользователю.

На втором ПК клонируйте этот репозиторий, выполните setup и выберите локальную базу. `settings.local.json`, базы и результаты исключены из Git. Переносите измерения кнопками JSON-экспорта/импорта: UUID исключает повторный импорт, конфликт содержимого отменяет всю транзакцию. Демо и реальные данные импортируются отдельно. Это ручной обмен, не автоматическая синхронизация. Не используйте файл SQLite одновременно с двух ПК по сетевой/синхронизируемой папке. Для параллельной работы с общей БД понадобится серверный слой.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
$env:QT_QPA_PLATFORM = 'offscreen'
.\.venv\Scripts\python.exe -m tests.ui_smoke
```

Тесты проверяют ограничения, отбраковку недостоверных данных, подбор, отключение при ошибке/остановке, сохранность таблиц кварцев и идемпотентный обмен между ПК. UI smoke выполняет полное демо-измерение и сохраняет снимок в `.scratch/ui-preview.png`.
